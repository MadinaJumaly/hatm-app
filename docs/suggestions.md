# Suggestions — ideas for later

These ideas aren't planned for v1 or v1.1. We'll review them after launch (Phase 5).

| Idea | Why it could help | Source |
|---|---|---|
| Change-log screen for the organizer | Settle "who unmarked my juz?" questions without opening the database | Phase 1 |
| Live progress updates | The progress list updates without reopening the app | Phase 1 |
| Push reminders before the deadline (where the phone supports them) | Fewer overdue juz, less manual reminding | Phase 1 |
| "Share to WhatsApp" button next to "copy link" | One tap instead of copy + paste | Phase 1 |
| Organizer 2FA or passkey | Stronger protection for the most powerful account | Phase 1 (security) |
| Second organizer / helper account | Lets someone stand in when the organizer is busy | Phase 1 |
| Export a group to CSV | An easy archive for the client and an extra backup | Phase 1 |
| Archive / hide finished khatms | Keeps the organizer's groups page short | Phase 1 |
| Link from each juz to its pages in an online mushaf | Lets participants without a printed mushaf read | Phase 1 |
| Larger-text switch inside the app | Older users don't have to change phone settings | Phase 1 (accessibility) |
| Completion message with a dua when 30/30 is reached | A nice moment for the group | Phase 1 |
| Custom domain on Cloudflare | Enables free WAF rate-limit rules against bots using up the daily quota (threat T9) | Phase 2 (security) |
| Raise PBKDF2 iterations if we ever move to a paid Workers plan | More CPU allows a slower hash; old hashes keep working (iterations stored per hash) | Phase 2 (security) |
| Several participant sessions per device (one per group) | A person in both groups doesn't need to log in again when switching | Phase 2 |
